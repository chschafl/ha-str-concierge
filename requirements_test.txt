# pytest-homeassistant-custom-component drives a deep transitive tree
# (it depends on `homeassistant` itself), and its version is what decides
# which Home Assistant the suite runs against. The floor has to keep us on
# an HA at or above the 2026.3.0 that hacs.json declares — otherwise CI
# would be green against a core that has no brands proxy and no
# `Integration.has_branding`, i.e. against code this integration doesn't
# support. 0.13.365 pins HA 2026.9.2, which needs Python >= 3.14.2.
pytest-homeassistant-custom-component>=0.13.365

# Test runner extras — let pip pick versions compatible with pytest-ha.
pytest
pytest-asyncio
pytest-cov
